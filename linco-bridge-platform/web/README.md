# Linco Bridge Web

[简体中文](README.zh-CN.md)

Vue 3 + Vite + Capacitor frontend for the Linco Bridge reference platform. The same TypeScript/Vue codebase builds a static Web app and an Android APK.

> See [`../server/README.md`](../server/README.md) for the backend and [`../README.md`](../README.md) for the full platform walkthrough.

## Framework decision

| Option | Decision |
| --- | --- |
| Keep UniApp | Rejected: HBuilderX, multi-target conditional compilation, and mini-program toolchains make packaging unnecessarily complex; Android is a hard requirement |
| React | Rejected: full rewrite of 48 Vue components and Pinia/Vue composables; no direct benefit for Android packaging |
| Tauri | Rejected: Android is possible, but Rust + NDK + a heavier native toolchain add complexity for this codebase |
| **Vue 3 + Vite + Capacitor** | Chosen: preserves Vue business logic, removes the UniApp compiler, keeps Web builds simple, and provides a mature Android shell |

## Stack

| Category | Choice |
| --- | --- |
| UI | Vue 3 + `<script setup lang="ts">` |
| Router | vue-router 4 |
| State | Pinia |
| Web build | Vite 5 + `@vitejs/plugin-vue` |
| Android shell | Capacitor 7 |
| Native plugins | Clipboard, Filesystem, App back button, Haptics, Share |
| Quality | ESLint, Prettier, Vitest, vue-tsc |

## Prerequisites

### Web

- Node.js 20+
- npm 10+

### Android

- JDK 17 recommended
- Android SDK Platform 35
- Android SDK Build Tools 35.0.0+
- `ANDROID_HOME` or `ANDROID_SDK_ROOT`
- Android emulator host API base: `http://10.0.2.2:3300`

## Quick Start

### 1. Start the backend

```bash
cd linco-bridge-platform/server
npm install
npm run start:dev
```

### 2. Start the Web frontend

```bash
cd linco-bridge-platform/web
npm install
npm run dev
```

### 3. Build Web

```bash
npm run build:web
```

Output: `web/dist/`.

## Android

```bash
npm run android:add   # only on first setup
npm run android:check
npm run android:dev   # build + cap sync + open Android Studio
```

Build a debug APK:

```bash
npm run cap:sync
cd android
./gradlew :app:assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

`android/` is generated by Capacitor and ignored by Git by default.

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Web dev server |
| `npm run build:web` | Web production build |
| `npm run build` | Alias of `build:web`, used by Capacitor |
| `npm run cap:sync` | Build and sync to Android |
| `npm run android:add` | Generate native Android project |
| `npm run android:check` | Validate Android SDK/JDK prerequisites |
| `npm run android:dev` | Sync and open Android Studio |
| `npm run android:build` | Sync and build a debug APK with Gradle |
| `npm run check` | typecheck + lint + format + test |

The old `dev:mp-weixin` / `build:mp-weixin` scripts now print a clear unsupported-platform message.
